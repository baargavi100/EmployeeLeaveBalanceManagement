# Employee Leave Balance Management Documentation

## 1. Project Overview
The Employee Leave Balance Management project aims to provide an efficient system for managing employee leave requests and their balances. This project facilitates tracking, approval, and reporting of various leave types to enhance workforce management.

## 2. Technology Stack
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Version Control:** Git
- **Hosting:** Heroku

## 3. Detailed Working Explanation
This project operates by allowing employees to submit leave requests through a user-friendly interface. The backend processes these requests, checking eligibility based on predefined leave policies, and updates the leave balance accordingly. It also allows HR to approve or reject requests and generate reports on leave utilization.

## 9. Setup Guide
### Pre-requisites:
- Node.js installed
- MongoDB setup
### Steps to Setup:
1. Clone the repository: `git clone https://github.com/baargavi100/EmployeeLeaveBalanceManagement.git`
2. Navigate to the backend folder: `cd EmployeeLeaveBalanceManagement/backend`
3. Install dependencies: `npm install`
4. Start the server: `node server.js`
5. Access the application on `http://localhost:3000`
